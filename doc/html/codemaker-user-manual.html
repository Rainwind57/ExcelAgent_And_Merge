用户 · 配表模式

CodeMaker 配表模式用户使用手册

面向在 CodeMaker 插件中配表的使用者。配表模式是项目「第二形态」：在 CodeMaker 对话框激活后，CodeMaker 仅用 skill 知识 + 后端原子 API 操作 resources/ 配表，轻量、受限、与其他项目内容隔离。全程自然语言，无需写代码。

与 Web 端的区别Web 端「AI 配表助手」是第一形态，功能全（含比对合并/浏览）；配表模式是第二形态，在 CodeMaker 插件里直接对话操作表格，轻量受限。两者共用同一后端。

1. 前置：启动后端

配表模式需要后端运行，也就是需要两个终端。

# 终端1 — CodeMaker Serve（LLM 底座）
$env:OPENCODE_SERVER_USERNAME="codemaker"
$env:OPENCODE_SERVER_PASSWORD="CMniubi2026"
codemaker serve --port 8666 --hostname 0.0.0.0

# 终端2 — 业务后端（提供原子 API）
Get-Content .env | Where-Object { $_ -and -not $_.StartsWith('#') } | ForEach-Object { $kv=$_.Split('=',2); Set-Item -Path ("env:"+$kv[0].Trim()) -Value $kv[1].Trim() }
uv run python server/main.py

后端运行在 http://127.0.0.1:8000。

5. 能力边界

操作支持说明
查询 / 搜索✅列表 / 搜索 / sheet 数据 / 列约束 / 相近项建议
改值（单格 / 多格）✅支持事务性多字段改值
新增行✅二段提交（先预览再写盘）
删除 / 插入行✅公式引用机械位移，会提示检查
列增删✅高风险，需确认
校验✅类型 / 唯一 / 跨表 ID
公式重写❌公式列只读，需退出后用 Web 端 agent 处理

6. 提示

  • 名称查询默认用“包含”匹配，多行命中会全部列出让你选。
  • 名称没命中时会给出相近项（含相似度），确认后再操作。
  • 新增行强制先预览再写盘，防误操作。
  • 配表模式仅能访问 resources/ 表格，其他项目文件无权访问；需要时先“退出配表模式”。

本手册面向使用者，技术细节见 配表模式技术文档；功能更全的 Web 端见 后端 Agent 用户手册。
