技术 · 配表模式

CodeMaker 配表模式技术使用文档

面向开发 / 维护人员：CodeMaker 配表模式（第二形态）的设计原理、安装机制、行为规则、知识库与原子 API。使用侧操作见 配表模式用户手册。

1. 定位与原理

配表模式是项目的第二形态，与 Web 端 AI 配表助手（第一形态）本质不同：

维度第一形态（Web Agent）第二形态（配表模式）
LLMcodemaker serve（后端完整 agent 解析）CodeMaker 自身 LLM
入口浏览器 :8000CodeMaker 插件对话框
后端角色业务 + LLM 编排 + Excel 读写仅提供原子 API 执行 Excel 读写
权限完整项目仅 resources/ 表格，其他隔离
意图理解/api/agent/chat（后端 LLM）CodeMaker LLM + skill 知识
核心分工CodeMaker = 意图理解 + 编排（大脑）；后端 = 执行引擎（读写 .xlsx、类型转换、校验、公式保护）。CodeMaker 不直接碰文件，只调后端原子 API。
关键约束配表模式下不调 /api/agent/chat 与 /api/agent/chat/stream（那是第一形态的后端完整 agent），改由 CodeMaker 自身 LLM 结合 skill 知识把自然语言拆解为具体原子 API 调用。

2. 安装机制

.codemaker/ 不提交（svn:ignore），配表模式需各成员本地生成。

2.1 自动安装

tools/deploy.bat（第 6 步）和 tools/update.bat（第 6 步）已自动安装，正常跑脚本即可。

2.2 手动重装

仅当单独改了 tools/table-mode/ 源文档或 server/agent/excel/skills/ 想立即生效时：

uv run python tools/table-mode/install.py

2.3 产物

安装后生成 .codemaker/table-mode/：

  • 配表操作模式.md — 模式行为指令（CodeMaker 进入后遵循）
  • 知识库.md — 配表知识（实体路由 / 列别名 / 行定位 / 原子 API）
  • skills/ — skill yaml 原文（列别名 / sheet 别名 / 行定位 / 反模式等）

源文档位于 tools/table-mode/（配表操作模式.md、知识库.md、install.py）。

3. 激活机制

  1. CodeMaker 识别「查看项目文件夹，进入配表模式」指令。
  2. 读 .codemaker/table-mode/配表操作模式.md（未安装则回退读 tools/table-mode/配表操作模式.md 源）并遵循。
  3. 询问确认 → 用户确认后读 知识库.md 加载规则 → 进入模式。
  4. 「退出配表模式」清除模式状态，恢复完整能力。
前提后端服务运行中 http://127.0.0.1:8000（python -m server.main 或 tools/start.bat）。

4. 行为规则（配表操作模式.md）

4.1 模式内权限

允许：

  • 读 .codemaker/table-mode/知识库.md + skills/ 下 skill 文件
  • 调后端原子 API 操作 resources/ 表格
  • 用 run_terminal_cmd 执行 curl 调原子 API

禁止：

  • 访问项目其他代码 / 文件（server/ frontend/ merge/ 等）
  • 调 /api/agent/chat 或 /chat/stream（后端完整 agent）
  • 执行与表格操作无关的请求（写代码、查项目结构、闲聊等）→ 统一拒答

4.2 操作流程

  1. 理解意图 — 解析用户自然语言。
  2. 查知识库解析 — 实体→表路由、sheet 别名、列别名、行定位。
  3. 调原子 API 执行 — 查询定位 → 改值 / 新增 / 删除。
  4. 返回结果 — 改了什么、旧值→新值、校验结果、跨表影响。

5. 知识库（知识库.md）

5.1 实体 → 表路由

自然语言实体类别映射到 table_stem（resources/ 下 xlsx 文件名去扩展名）。例：

实体table_stem主 sheet
灵兽/宠物petPet
法宝fabaoFabao
神通abilityAbility
道具itemItemBase/ItemType
建筑buildingBuildingType

5.2 别名体系

  • Sheet 别名（sheet_aliases.yaml）：业务别名 → 真实 sheet（如「法宝等级」→FabaoLevel）。
  • 列别名 / 短形式 / 中英对照（column_aliases.yaml 等）：如「名字」→名称、「攻击」→atk。
  • 行定位（row_aliases.yaml）：默认 locator_column=名称、match=contains。
  • 解析器配置（parser_config.yaml）：前导动词剥离（给/将/把/为...）、非业务 sheet 跳过标记。
R25 真实名优先表结构变更后别名 yaml 可能滞后。解析时优先调 GET /api/tables/{stem} 取真实 sheet 名、?include_columns=1 取真实列名，别名 yaml 仅作兜底。后端启动时 regenerate_skills 重算 L1_derived 保持同步。

6. 原子 API 清单

base URL：http://127.0.0.1:8000，用 curl 调用。

6.1 查询类

方法路径说明
GET/api/tables所有表列表
GET/api/tables/search?q=&table=全文搜索
GET/api/tables/{stem}表详情
GET/api/tables/{stem}/sheets/{sheet}?page=&page_size=&include_columns=1sheet 分页数据（include_columns=1 同返列约束）
GET/api/tables/{stem}/sheets/{sheet}/columns列约束
GET/api/tables/{stem}/sheets/{sheet}/suggest?value=&col=&top=3R19 相近项建议
GET/api/validate/id-scope跨表 ID 校验 + 查重
行号定位data_start 是数据起始 Excel 行号（1-based），页内索引 ri → Excel 行号 = data_start + (page-1)*page_size + ri。

6.2 改值

  • POST /api/tables/cell/update {table_stem, sheet, row, col, value} — 单格。
  • POST /api/tables/cells/batch-update {..., atomic, updates:[{col,value}]} — R22 多字段批量，atomic=true 全成或全败。

6.3 新增行（R23 二段提交）

  1. POST /api/tables/add-form/build {text} → {columns, empty_row}
  2. POST /api/tables/add-form/validate {table_stem, sheet, values} → errors/warnings
  3. POST /api/tables/add-form/commit：先 dry_run=true 预览（不写盘）→ 用户确认后 dry_run=false 写盘返回 new_row

6.4 行/列增删（R24）

  • POST /api/tables/row/delete {table_stem, sheet, row}
  • POST /api/tables/row/insert {table_stem, sheet, row, values?}
  • POST /api/tables/column/add / column/delete {..., confirm} — 必须 confirm=true，高风险。

7. 关键行为规则（R 系列）

编号规则
R19名称定位失败 → suggest 取 top-3 相近项 → 展示候选卡片供用户选 → 仍无则全文 search
R20同名列消歧：columns_meta 含 {col_index, name}，回显标注 激活消耗(列3)，cell/update 用 col 号区分
R21改值前用 ?include_columns=1 一次取行数据 + 列约束
R22多字段改值用 cells/batch-update，事务性
R23新增行强制二段提交（先 dry_run 预览再写盘）
R24行/列增删；列操作需 confirm
R25真实名优先，别名 yaml 兜底
R27公式列只读不改，提示用户手动处理

8. 安全规则

  • 改值前先查：sheet 数据 + columns 约束，确认行号/列号/类型/唯一性。
  • 唯一列查重：改值前搜该列是否已有相同值。
  • 公式列保护：标记为公式的列不直接覆写，提示风险。
  • ID 列改动：改 id 后调 /api/validate/id-scope 校验跨表冲突。
  • 新增先校验：validate 通过再 commit，confirm=true 仅用户明确确认时用。
  • 值类型：数字列传数字字符串（"100"），后端转换。

9. 故障排查

现象原因 / 处理
CodeMaker 找不到 配表操作模式.md.codemaker/table-mode/ 未安装，跑 install.py 或 deploy.bat/update.bat
API 调用连接失败后端未启动，检查 :8000
curl 带中文参数报 Invalid HTTP request用 curl --get --data-urlencode 对中文参数做 URL 编码
别名与真实结构不符重启后端触发 regenerate_skills，或依 R25 直接取真实名
名称查不到触发 R19，从相近项建议中选，或改用其他列定位
