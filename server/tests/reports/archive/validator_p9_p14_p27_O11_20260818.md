## 根因归因

| 修复项 | 贡献 | 证据 |
|---|---|---|
| P9 multi_op 标记 | 原 `_suppress_over_produce` 一表一 op 契约下，用户显式多 producer 同 sheet（如两 prefab 不同 sheet 但同 stem... 实际同 sheet 多 producer）被当 LLM 过产抑制第二个。加 `multi_op_same_sheet=True` 标记跳过，保留用户显式意图。注：4-step 不调 `_suppress` → 仅 fallback 路径。 | `test_suppress_keeps_multi_op_same_sheet_marked` + `test_suppress_mixed_only_unmarked_deduped` |
| P14 可观测 | `_llm_judge_forward_ref` 5 个 `return ""` 静默 → LLM 不可达时行为不确定（可放行可阻断）。加 `logger.warning` 使每次「放行」留痕可复现。返回 "" 非阻断语义不变。 | `test_no_session_returns_empty_with_warning` + `test_exception_returns_empty_with_warning` + 4 其他 |
| P27 序列化层 | 4-step NL 路径 stall/放弃 → 从 Step1 重 LLM decompose（N 次 LLM 成本白花）。NLIntent `to/from_checkpoint_dict` + agent_service `_save/_load_nl_checkpoint` 拍 parse/validate 后中间态，续跑可免重 decompose。序列化能力 + round-trip 单测已落地。 | `test_round_trip_basic` + `test_round_trip_with_validation/execution` + `test_save_load_round_trip` |

- P9 4-step `validate_two_layer` 不调 `_suppress_over_produce` → 此修复仅 fallback `validate()` 路径生效。DecomposeAgent 标注 `multi_op_same_sheet=True` 的接线留 follow-up（当前无生产接线，能力 + 单测已备）。
- P14 opt-in 路径（`CODEMAKER_VALIDATOR_LLM_FORWARD_REFS=1`，默认 off）。warning 不阻断，返回 "" 非阻断（交写后 ref_integrity 真验证，design D2）。
- P27 4-step 路径接线（`_save_nl_checkpoint` 调用点 + stall 检测 + resume 时 `_load_nl_checkpoint` + skip已成功 Step5 op）留 follow-up。当前序列化能力 + agent_service 存取方法 + round-trip 单测已落地；续跑协议（stall 检测 + skip已成功 + 中间态恢复）需独立提案。
