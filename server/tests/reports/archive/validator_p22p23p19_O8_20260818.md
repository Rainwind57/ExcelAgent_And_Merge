## 注意事项

- P23 设计决策：软失败 dict 用 `status:"soft"` 区别于 hard failure（placeholder_unresolved 等仍 `status:"unresolved"`）。前端可据此区分展示。`type:"validation_tip"` 标识来源。
- P23 不幂等：同一 tips 两次 attach 会累加（`test_idempotent_append` 验证），调用方负责去重。本路径只在 validate_two_layer 后调一次，无重复风险。
- P23 不改 O3 非阻断语义：tips 仍供 thinking 展示（原行为保留），同时进 intent.failures 上报（新增）。展示 + 上报双通道。
- P19 不强制改配置：warning 提示仅告知，不自动关 verify_repair（保用户显式意图）。CI/自动化应避免此组合（显式设 CODEMAKER_VERIFY_REPAIR_LOOP=0 或不设 EXECUTE_NO_LLM）。
- P24/P25（skip partial 态：重激活 _mark_validation_skipped + _phase_execute:5446 + 汇总单列"已跳过清单"）+ P21（validate() 与 validate_two_layer() 校验集合统一）留 O9。
- LLM e2e `table_case_eval.py` 未跑：R7 阻断（serve agentic LLM 慢/贵，非 excel-agent code 可修，ledger §2.1）。
